# Карточки: английский и словацкий

Приложение для запоминания слов с интервальным повторением. Один файл `index.html`, без сервера и установки.

## Как выложить на GitHub Pages

1. Создайте публичный репозиторий.
2. Загрузите в него все файлы из этой папки (Add file → Upload files).
3. Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты откройте ссылку `https://ваш-логин.github.io/название-репозитория/`.

## Прогресс

Прогресс хранится в браузере. Открывайте приложение всегда по одной ссылке и в одном браузере.
Резервная копия: настройки → «Показать данные» (сохраните текст) и «Восстановить».

## Функции с ИИ

Разделы «Разговор», «Грамматика», «Ситуации» и «Примеры» работают только внутри приложения Claude.
На GitHub Pages они покажут сообщение «ИИ здесь недоступен». Остальное работает полностью.
